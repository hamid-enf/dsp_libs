# Biquad — نظریه و ریاضیات

## ۱. معرفی
فیلتر مرتبه‌ی ۲ (Second-Order Section): بلوک اصلی ساخت فیلترهای مرتبه‌ی
بالاتر (SOS Cascade) و اکولایزرهای صوتی. موتور این کتابخانه ۸ نوع فیلتر را
با فرمول‌های RBJ (Robert Bristow-Johnson) محاسبه می‌کند.

## ۲. کاربرد
- اکولایزر پارامتریک (Peak/Shelf)، ناچ ۵۰/۶۰Hz
- کراس‌اوور صوتی، فیلترهای حسگر، سنتز
- بلوک پایه‌ی هر فیلتر IIR مرتبه‌ی بالا

## ۳. مزایا
- فرمول بسته‌ی ضرایب (RBJ) — بدون نیاز به طراحی عددی
- کمترین هزینه برای یک قطب-صفر جفت: ۵ MAC/sample
- قابل تنظیم Runtime (Fs/Fc/Q/Gain)

## ۴. معایب
- فقط ۲ قطب — برای گزینش‌پذیری زیاد باید چند طبقه زنجیره شود
- Q بالا → حساسیت عددی (مخصوصاً Fixed)

## ۵. محدودیت‌ها
- در Fixed فقط DF1؛ Q > ~10 در Q15 توصیه نمی‌شود (مستندات را ببینید)
- fc باید < fs/2 و Q > 0

## ۶. مدل ریاضی
تابع تبدیل (با a0 = 1):

$$H(z) = \frac{b_0 + b_1 z^{-1} + b_2 z^{-2}}{1 + a_1 z^{-1} + a_2 z^{-2}}$$

معادله‌ی تفاضلی:

$$y[n] = b_0 x[n] + b_1 x[n-1] + b_2 x[n-2] - a_1 y[n-1] - a_2 y[n-2]$$

## ۷. فرمول ضرایب (RBJ)

تعریف: $\omega_0 = 2\pi f_c/f_s$، $\alpha = \dfrac{\sin\omega_0}{2Q}$،
$A = 10^{G/40}$.

| نوع | b0 | b1 | b2 | a1 | a2 |
|-----|----|----|----|----|----|
| LPF | (1−c)/2 | 1−c | b0 | −2c | 1−α |
| HPF | (1+c)/2 | −(1+c) | b0 | −2c | 1−α |
| BPF | α | 0 | −α | −2c | 1−α |
| Notch/BSF | 1 | −2c | 1 | −2c | 1−α |
| Peaking | 1+αA | −2c | 1−αA | −2c | 1−α/A |
| Low-Shelf | A[(A+1)−(A−1)c+2√A·α] | 2A[(A−1)−(A+1)c] | A[(A+1)−(A−1)c−2√A·α] | −2[(A−1)+(A+1)c] | (A+1)+(A−1)c−2√A·α |
| High-Shelf | A[(A+1)+(A−1)c+2√A·α] | −2A[(A−1)+(A+1)c] | A[(A+1)+(A−1)c−2√A·α] | 2[(A−1)−(A+1)c] | (A+1)−(A−1)c−2√A·α |

که در آن $c = \cos\omega_0$ و همه‌ی ضرایب بر $a_0$ تقسیم می‌شوند.

## ۸. تعریف متغیرها
- $f_c$: فرکانس مرکزی/قطع، $f_s$: نرخ نمونه، $Q$: ضریب کیفیت
  ($Q = f_c/\text{BW}$)، $G$: گین (dB، برای Peak/Shelf).

## ۹. انتخاب پارامترها
- LPF/HPF: fc = نقطه‌ی −3dB، Q ≈ 0.707 (Butterworth) برای مسطح‌ترین پاس‌باند.
- Notch: Q = 30..60 برای ۵۰Hz (پهنای باند ~fc/Q).
- Peak: Q ~ 0.5..2 در صدا؛ G تا ±12dB.

## ۱۰. اثر تغییر پارامترها
- افزایش Q → رزونانس تیزتر، گذار کوتاه‌تر، حساسیت عددی بیشتر.
- افزایش G در Peak → دامنه‌ی پیک؛ در Shelf → سطح باند.

## ۱۱. اثر روی Phase
TDF2/DF1 همان پاسخ فاز دارند؛ Q بالا → شیب فاز تندتر. Shelf ها تغییر فاز
ملایم‌تری دارند.

## ۱۲. اثر روی Magnitude
- LPF: −3dB@fc با Q=0.707؛ با Q>0.707 پیک پاس‌باند.
- Notch: صفر کامل در fc (در Fixed تا ~−40dB به‌دلیل کمی‌سازی).
- Peak: گین دقیق A در fc.

## ۱۳. اثر روی Noise
در Fixed، نویز کمی‌سازی state در DF1 ≈ یک LSB؛ در TDF2 (فقط float) مشابه.
Q بالا خطای گردکردن را در باند تشدید می‌کند.

## ۱۴. اثر روی Stability
پایدار اگر |قطب| < 1: برای قطب‌های مزدوج $r e^{\pm j\theta}$:
$a_1 = -2r\cos\theta$، $a_2 = r^2$؛ شرط $|a_2| < 1$ و $|a_1| < 1+a_2$.

## ۱۵. اثر روی CPU
۵ MAC + ذخیره‌سازی state به ازای هر نمونه (TDF2) — ~10-20 سیکل روی M7.

## ۱۶. اثر روی RAM
Single: ۱۲ float داخل struct. Cascade: ۲×طبقه float.

## ۱۷–۲۲. مثال‌ها
- STM32H7: مثال‌های ۳ (BPF+FFT) و ۴ (اکولایزر ۳ باند I2S)
- Sample: `dsp_biquad_process_sample_f32(&bq, x, &y)`
- Block: `dsp_biquad_process_block_f32(&bq, in, out, n)`
- Runtime: `dsp_biquad_set_params_f32(&bq, type, fs, fc, q, gain)` در هر لحظه
- ADC: DCBlocker → Biquad → FFT (مثال ۳)
- Audio: زنجیره‌ی ۳ Biquad برای اکولایزر ۳ باند (مثال ۴)

# Biquad — نکات پیاده‌سازی

- ضرایب با `dsp_biquad_set_params*` از فرمول‌های RBJ (float64 داخلی) تولید و
  سپس به دقت هدف (f32/f64/q15/q31) تبدیل می‌شوند.
- در Q15/Q31، کمی‌سازی خودکار: $s = -1-\lceil\log_2(\max|c_i|)\rceil$،
  ضرایب $C_i = \text{round}(c_i 2^{15+s})$ و خروجی $y = \text{sat}((acc + 2^{shift-1})>>shift)$
  با $shift = 15+s$. ورودی ≤ ~0.5 تمام‌مقیاس → بدون سرریز تضمینی.
- `dsp_biquad_get_coeffs*` برای مشاهده‌ی ضرایب (Validation، ذخیره/بارگذاری).
- بعد از هر `set_params`/`set_coeffs`، state پاک می‌شود (بدون کلیک).
