# Notch — حذف فرکانس مشخص

## ۱. معرفی
فیلتر Biquad که یک فرکانس (و باند باریک اطراف آن) را حذف می‌کند.

## ۲. کاربرد
- حذف **50Hz/60Hz** (هم‌نویز شبکه) از سیگنال ADC/ECG/صدا
- حذف هارمونیک موتور، وِیر PWM

## ۳. مزایا
- تنظیم Runtime (fs/fn/Q) بدون طراحی پیچیده
- ضریب‌های بسته (RBJ)

## ۴. معایب
- Q بالا → حساسیت عددی (مخصوصاً Fixed) و گذرای طولانی
- فقط یک فرکانس (برای چند فرکانس، چند ناچ زنجیره شود)

## ۵. محدودیت‌ها
- fn باید < fs/2 و با حاشیه از لبه‌ها

## ۶. مدل ریاضی
$$\omega_0 = 2\pi f_n/f_s,\qquad \alpha = \frac{\sin\omega_0}{2Q}$$

$$H(z) = \frac{1 - 2\cos\omega_0\, z^{-1} + z^{-2}}
{1 - 2\cos\omega_0\, z^{-1}/(1+\alpha) + (1-\alpha) z^{-2}/(1+\alpha)}$$

## ۷–۸. متغیرها
$f_n$: فرکانس ناچ، $Q$: کیفیت (پهنای باند = fn/Q)، $f_s$: نرخ نمونه.

## ۹. انتخاب پارامترها
- 50Hz@1kHz با Q=30 → پهنای ~1.7Hz (تأثیر کم روی سیگنال).
- برای هارمونیک‌های نزدیک به سیگنال، Q کوچک‌تر تا فاز کمتر آسیب ببیند.

## ۱۰–۱۴. اثرها
- گین در fn ≈ 0 (در Fixed تا ~−40dB).
- فاز: انحراف شدید نزدیک fn؛ دور از fn تقریباً صفر.
- پایداری: قطب‌های داخل دایره‌ی واحد (پایدار).
- CPU: ۵ MAC؛ RAM: ۲ float.

## ۱۷–۲۲. مثال‌ها
```c
dsp_notch_f32_t nf;
dsp_notch_init_f32(&nf, 48000, 50, 30);        /* حذف 50Hz */
dsp_notch_process_f32(&nf, x, &y);
dsp_notch_set_freq_f32(&nf, 48000, 60, 30);    /* تغییر Runtime به 60Hz */
```
Audio/I2S: زنجیره‌ی Notch قبل از اکولایزر؛ ADC: حذف هم‌نویز قبل از FFT.
