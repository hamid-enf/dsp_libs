# Kalman 1D — فیلتر کالمن

## ۱. معرفی
تخمین‌گر بازگشتی بهینه (به معنای کمترین واریانس خطا) برای سیستم‌های خطی
گاوسی. نسخه‌ی 1D با دینامیک ثابت — معماری آماده‌ی گسترش به چندبعدی/EKF.

## ۲. کاربرد
- Sensor Fusion (مثال ۸)، IMU/GPS، رباتیک
- تخمین کمیت با نویز اندازه‌گیری معلوم (دما، ولتاژ، موقعیت)

## ۳. مزایا
- بهینه در MSE برای مدل درست
- RAM بسیار کم (۵ float)
- سازگار با نرخ‌های نامنظم (predict بین اندازه‌گیری‌ها)

## ۴. معایب
- نیاز به برآورد Q و R (عدم تطابق → تخمین غیربهینه)
- مدل ثابت (برای دینامیک متغیر، به حالت برداری/EKF نیاز است)

## ۵. محدودیت‌ها
- فقط float32 (Fixed نامناسب — به نقد معماری مراجعه کنید)

## ۶. مدل ریاضی
مدل: $x_k = x_{k-1} + w_k$ ($w\sim N(0,Q)$)، $z_k = x_k + v_k$ ($v\sim N(0,R)$)

**پیش‌بینی:**
$$\hat{x}^-_k = \hat{x}_{k-1}, \qquad P^-_k = P_{k-1} + Q$$

**به‌روزرسانی:**
$$K_k = \frac{P^-_k}{P^-_k + R}, \qquad
\hat{x}_k = \hat{x}^-_k + K_k(z_k - \hat{x}^-_k), \qquad
P_k = (1-K_k)P^-_k$$

## ۷–۸. متغیرها
$x$: حالت (کمیت هدف)، $P$: کوواریانس خطای تخمین، $K$: گین کالمن، $Q$:
واریانس نویز فرآیند (چقدر مدل متغیر است)، $R$: واریانس نویز اندازه‌گیری،
$z$: اندازه‌گیری.

## ۹. انتخاب پارامترها
- $R$: از دیتاشیت حسگر/کالیبراسیون (واریانس نویز).
- $Q$: نرخ تغییر واقعی کمیت؛ اگر خیلی کوچک → تأخیر زیاد (اعتماد بیش از حد
  به مدل)؛ اگر بزرگ → نویزی (اعتماد زیاد به اندازه‌گیری).
- $P_0$: بزرگ (مثلاً 1) → همگرایی سریع در شروع.

## ۱۰–۱۴. اثرها
- K بزرگ (R کوچک) → پاسخ سریع + نویزی؛ K کوچک → هموار + تأخیر.
- P به سمت مقدار پایدار $(Q+\sqrt{Q^2+4QR})/2$ همگرا می‌شود.
- پایداری: برای Q,R≥0 همیشه پایدار.
- CPU: ~۱۰ عملیات؛ RAM: ۵ float — سبک‌ترین فیلتر کتابخانه.

## ۱۷–۲۲. مثال‌ها
مثال ۸ (فیوژن دو حسگر). API:

```c
dsp_kalman1d_f32_t kf;
dsp_kalman1d_init_f32(&kf, 0.0f, 1.0f, 1e-4f, 0.25f);
dsp_kalman1d_process_f32(&kf, z, &x);       /* پیش‌بینی+به‌روزرسانی */
dsp_kalman1d_predict_f32(&kf);              /* فقط پیش‌بینی (نرخ نامنظم) */
dsp_kalman1d_update_f32(&kf, z, &x);        /* فقط به‌روزرسانی */
dsp_kalman1d_set_noise_f32(&kf, q, r);      /* تنظیم Runtime */
```

**توسعه‌پذیری:** برای چندبعدی، همین ساختار با ماتریس‌ها (P, K, H) تعمیم
می‌یابد — مسیر در مستندات Roadmap مشخص شده است.
